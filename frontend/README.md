# E-Commerce Frontend

Frontend del proyecto E-Commerce desarrollado con Next.js 14+, TypeScript y Tailwind CSS.

---

## Tecnologías utilizadas

- Next.js 14+
- React
- TypeScript
- Tailwind CSS

---

## Estructura del proyecto

src/
├── app/
│ ├── login/
│ │ └── page.tsx
│ ├── registro/

│
