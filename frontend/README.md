# Frontend - E-Commerce

Este proyecto corresponde al módulo Frontend del sistema E-Commerce. Fue creado con Next.js 14, TypeScript y Tailwind CSS.

## Tecnologías utilizadas

- Next.js 14
- TypeScript
- Tailwind CSS
- ESLint
- App Router
